1. 技术原理与架构演进

在 TypeSafe Jev /v1/systemone 复合问卷中，用户通常针对一个长上下文轨迹（state）提出多个原子判定准则。传统实现对每个原子题均需将整个 state 重新编码，计算复杂度为 \(N \times (C_{state} + C_q)\)。 

传统独立前向:  [State + Q1] -> Forward
              [State + Q2] -> Forward  (重复 Prefill 长文本 N 次)
              ...

共享前缀优化:  [State] -> Single Prefill -> Base KV Cache (驻留统一内存)
              ├─> Clone Cache -> [Q1] -> Readout Position Logits
              ├─> Clone Cache -> [Q2] -> Readout Position Logits
              └─> 复杂度缩减为: C_{state} + N * C_q
